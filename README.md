# C++ Calculator

Учебный проект калькулятора на C++ с графическим интерфейсом на Qt.

## О проекте

Приложение выполняет арифметические вычисления и демонстрирует разделение логики приложения и пользовательского интерфейса.

В проекте используются отдельные компоненты для:

- вычисления выражений;
- работы с рациональными числами;
- возведения в степень;
- управления состоянием приложения;
- взаимодействия с графическим интерфейсом Qt.

## Технологии

- C++17
- Qt Widgets
- qmake
- ООП

## Структура проекта

- `calculator/` — исходный код приложения;
- `calculator.h` — логика калькулятора;
- `rational.h` — работа с рациональными числами;
- `pow.h` — операции возведения в степень;
- `controller.h` — управление вычислениями;
- `mainwindow.*` — графический интерфейс;
- `submission.pro` — конфигурация сборки qmake.

## Сборка

Для сборки необходимы Qt с поддержкой Qt Widgets и компилятор C++17.

Откройте `calculator/submission.pro` в Qt Creator или соберите проект с помощью qmake.

## Цель проекта

Проект выполнен в рамках обучения C++ и предназначен для практики работы с ООП, разделения ответственности между компонентами и создания приложений с Qt.
